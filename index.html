How it works

Up and running
in under 60 seconds

1

Install Brain Care

Add it to Chrome from the Web Store in one click. No account, no sign-up required.

2

Create your passcode

Set a secure admin passcode on first launch. Only you know it — students can't change settings without it.

3

Add sites to block

Type any domain or tap a quick-add preset — YouTube, TikTok, Kick, adult sites, and more. Blocked instantly.

Students are protected

When a student visits a blocked site, they see a clear "Site Blocked" page. Only your passcode can unlock it.
